# UPI Checkout & Receipt Flow 

A fintech-style UPI payment UI built using **HTML, CSS, and JavaScript**.  
This project validates UPI ID format, simulates payment success/failure, and generates a receipt with a unique transaction ID.

##  Live Demo
https://upi-checkout-receipt-vishali.netlify.app/

##  Features
- 1. UPI ID validation (name@bank format)
- 2. Payment processing loader UI
- 3. Success / Failed simulation
- 4. Transaction ID generation
- 5. Receipt view with full details
- 6 Download receipt using Print-to-PDF
- 7. Responsive and modern UI

##  Tech Stack
- HTML
- CSS
- JavaScript

##  How to Run Locally
1. Download or clone this repository
2. Open `index.html` in your browser
